## Quick Start Guide (3 Steps)


### 1. Extract & Navigate

Extract the archive and move into the project directory:

  unzip MediaShield_Suite_v1.0.0.zip
  cd mediashield_release


### 2. Make Executable & Install

Give execution permissions to the scripts and run the installer:

  chmod +x install.sh media_shield_process.sh media_shield_watch.sh
  ./install.sh


### 3. Configure & Run

1. Open `config.env` and insert your license key and setup configuration.
2. Start watching your media directory:

  ./media_shield_watch.sh
